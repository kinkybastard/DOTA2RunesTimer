# DOTA2RunesTimer
This is a Dota 2 timer that helps you better track rune spawns on the map. It displays currently available runes and the time remaining until they spawn next.

It supports Bounty, Power, Water, and Wisdom runes, as well as Lotus and Tormentor. It can be used in Turbo or All Pick mode.

## **Warning**
This program will only be visible in-game if the "Display mode" graphics setting is set to **"Borderless Window."** If the game is launched in "Fullscreen" mode, the timer will be obscured.

Try enabling V-Sync if you are getting low FPS with it on.

## Requirements
.NET 10 must be installed on your PC. [Download link](https://dotnet.microsoft.com/ru-ru/download/dotnet/10.0)

## How use
1. Select Turbo or All Pick mode.
2. During the match, press the "Start" button 30 seconds before the first Bounty appear in the river (before the match begins).
3. If the game is paused, press the "Pause" button. Press "Start" when the game resumes.
4. If the app's timer lags behind the Dota 2 game time, adjust it using the "+" and "-" buttons.
5. The "Reset" button stops the timer and resets it to 00:00.
